# 💫 About Me:
- 자동차공학을 기반으로 전기차와 자율주행 등 빠르게 변화하는 자동차 기술에 관심을 가지고 역량을 넓혀가고 있습니다.<br>
- 기계적인 자동차 기술뿐만 아니라 소프트웨어와 전자 기술이 결합된 미래 모빌리티 분야까지 역량을 확장하고 있습니다.<br>
- 자동차에 대한 관심을 공학적 지식으로 발전시키고, 배운 내용을 실제 문제 해결에 활용할 수 있는 인재입니다.<br>
- 끊임없이 배우고 직접 경험하며, 배운 것을 자신의 역량으로 만들어가는 사람입니다.<br>
- 관심에서 시작한 자동차에 대한 열정을 전문적인 지식과 실무 역량으로 발전시키고 있습니다.
